## Key Takeaways

- Responsible AI considers fairness, privacy, transparency and accountability.
- Biased data can produce unfair model outcomes.
- Sensitive information should be minimized and protected.
- AI-generated answers need verification.
- External documents and tool outputs should be treated as untrusted data.
- Prompt instructions alone cannot guarantee security.
- Human oversight is important for consequential decisions.
- Safety requires multiple layers of protection and testing.

## Limitations

The safety checks in this notebook are educational demonstrations, not production security systems.
