## Hands-on Project: Streaming AI Assistant

Build a small AI assistant that displays responses progressively instead of waiting for the entire answer.

### Features

- Accept user questions through Python input.
- Generate responses using the OpenAI API.
- Stream generated text as it arrives.
- Limit output tokens using `max_output_tokens`.
- Display the response progressively.

### Example

```python
def streaming_assistant(prompt):

    stream = client.responses.create(
        model="gpt-4.1-mini",
        input=prompt,
        max_output_tokens=250,
        stream=True
    )

    print("AI Assistant: ", end="")

    for event in stream:

        if event.type == "response.output_text.delta":
            print(event.delta, end="", flush=True)

    print()
```

## Additional Project: Token Cost Calculator

Create a Python function that estimates API costs based on input and output token counts.

```python
def calculate_cost(input_tokens, output_tokens,
                   input_rate, output_rate):

    input_cost = (input_tokens / 1_000_000) * input_rate

    output_cost = (output_tokens / 1_000_000) * output_rate

    total_cost = input_cost + output_cost

    return total_cost
```

**Note:** Use the actual current pricing for your selected model. Any example rates used during practice are hypothetical.
