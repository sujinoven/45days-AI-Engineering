## 📅 Day 01 — LLM Fundamentals

**Project:** Next-Token Prediction Simulator

Built a Python program to simulate how LLMs select tokens using probabilities and temperature.

### 🧠 Concepts Learned
- LLMs and next-token prediction
- Probability distributions
- Temperature and random sampling
- Python functions and dictionaries

### 🛠️ Tech Stack
Python | VS Code | Git | GitHub

### ▶️ Run the Project
```bash
python Day_01/01_token_simulator.py
```

### 🔍 Key Learning
- Low temperature → More predictable output
- High temperature → More varied output
- Temperature 0 → Selects the highest-probability token
