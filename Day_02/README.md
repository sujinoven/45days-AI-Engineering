# 🧠 Day 02 — Neural Networks

## Project: Training a Single Neuron Using Python

Built a simple trainable neuron from scratch using Python and Gradient Descent.

### 🎯 Objective
Understand how neural networks learn by adjusting weights and biases to minimize prediction errors.

### 📚 Concepts Learned
- Artificial neurons
- Weights and biases
- Forward propagation
- Loss function (Mean Squared Error)
- Gradients and derivatives
- Gradient descent
- Learning rate and epochs
- Supervised learning

### 🛠️ Tech Stack
- Python 3
- Jupyter Notebook
- Git & GitHub

### 💻 Project Details

The model learns the mathematical relationship:

`y = 2x + 1`

It uses training examples to learn the weight and bias, then predicts the output for a new input.


### 🔑 Key Learnings
- Weights determine the influence of inputs.
- Bias adjusts the model's output.
- Loss measures prediction errors.
- Gradients help determine parameter updates.
- Gradient descent reduces the loss through repeated training.

### 🎯 Expected Result

The model should learn approximately:

- Weight = 2
- Bias = 1
- Prediction for x = 10 → 21
