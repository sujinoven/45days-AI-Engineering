# Day 40 — Unsupervised Learning and Clustering

## Learning Objectives

- Understand supervised and unsupervised learning.
- Understand clustering and its applications.
- Implement K-Means clustering.
- Choose the number of clusters using the elbow method.
- Evaluate clusters using silhouette scores.
- Understand why feature scaling matters.
- Build a customer segmentation project.

## Topics Covered

1. Introduction to unsupervised learning
2. Types of unsupervised learning
3. K-Means clustering
4. Centroids and cluster assignments
5. Elbow method and inertia
6. Silhouette score
7. Feature scaling with StandardScaler
8. Customer segmentation

- Applied feature scaling.
- Built a customer segmentation example.

## Key Takeaways

- Unsupervised learning discovers patterns without target labels.
- K-Means groups data points around centroids.
- The elbow method helps investigate the number of clusters.
- Silhouette scores measure cluster separation and cohesion.
- Feature scaling is important for distance-based algorithms.
- Cluster IDs do not have an inherent business meaning.
